# CLI

The package ships a `next-smart-router` binary that generates a route manifest
by walking your Next.js `app/` directory.

## Usage

```
next-smart-router generate [options]
```

| Option | Description | Default |
| --- | --- | --- |
| `--app-dir <path>` | Path to the Next.js `app` directory | `./app` |
| `--out, -o <path>` | Output file (`.json` → JSON, else a TS module) | `./route-manifest.ts` |
| `-h, --help` | Show help | — |

## Examples

```bash
# default: ./app -> ./route-manifest.ts
npx next-smart-router generate

# custom src/app layout
npx next-smart-router generate --app-dir src/app --out src/route-manifest.ts

# JSON output
npx next-smart-router generate -o src/routes.json
```

## Walking rules

The generator mirrors Next.js App Router conventions:

| Folder | Behavior |
| --- | --- |
| `(group)` | Stripped — contributes no path segment. |
| `[id]`, `[...slug]`, `[[...slug]]` | Preserved as-is in the pattern. |
| `api/` | Ignored. |
| `_anything/` | Ignored (private folders). |
| `@slot/` | Ignored (parallel routes). |

A directory is treated as a route only if it contains a page file
(`page.tsx`, `page.ts`, `page.jsx`, or `page.js`). The root `/` is always
included.

## Output formats

**TypeScript** (default, or any non-`.json` extension):

```ts
/* AUTO-GENERATED by next-smart-router — DO NOT EDIT */
export const ROUTES = new Set([
  "/",
  "/workspaces/[id]",
]);
```

**JSON** (`.json` extension):

```json
[
  "/",
  "/workspaces/[id]"
]
```

Consume JSON like so:

```ts
import routesJson from "@/routes.json";
import { initializeSmartRouter } from "next-smart-router";

initializeSmartRouter({ routes: routesJson });
```

## Keep it in sync

Regenerate on every dev/build so the manifest never drifts from your routes:

```jsonc
// package.json
{
  "scripts": {
    "predev": "next-smart-router generate --app-dir src/app --out src/route-manifest.ts",
    "prebuild": "next-smart-router generate --app-dir src/app --out src/route-manifest.ts"
  }
}
```

## Programmatic use

Everything the CLI does is available from `next-smart-router/cli`:

```ts
import { generateRoutes, collectRoutes } from "next-smart-router/cli";

// write a manifest
generateRoutes({ appDir: "src/app", out: "src/route-manifest.ts" });

// just collect the patterns (no file written)
const routes = collectRoutes("src/app");
```
