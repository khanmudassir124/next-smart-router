# Getting Started

## Requirements

- Next.js **13+** (App Router). The core helpers also work standalone.
- React **16.8+** (only for the `next-smart-router/react` hook).

Both `next` and `react` are declared as **optional peer dependencies** — the
core entry (`next-smart-router`) imports neither, so you can use `getParams`,
`getBreadcrumbs`, etc. in any environment.

## Install

```bash
npm install next-smart-router
# or
pnpm add next-smart-router
# or
yarn add next-smart-router
```

## Step 1 — Generate a route manifest

next-smart-router needs to know your app's route patterns. Generate them from
your `app/` directory:

```bash
npx next-smart-router generate --app-dir src/app --out src/route-manifest.ts
```

This walks `app/`, following Next.js conventions:

- Route groups `(group)` contribute **no** path segment.
- `api/`, `_private/`, and `@parallel/` folders are **ignored**.
- Dynamic (`[id]`), catch-all (`[...slug]`) and optional catch-all
  (`[[...slug]]`) segments are **preserved**.

Output (`src/route-manifest.ts`):

```ts
/* AUTO-GENERATED by next-smart-router — DO NOT EDIT */
export const ROUTES = new Set([
  "/",
  "/workspaces",
  "/workspaces/[id]",
  "/workspaces/[id]/settings",
  "/docs/[...slug]",
]);
```

Keep it fresh by wiring it into your scripts:

```jsonc
// package.json
{
  "scripts": {
    "predev": "next-smart-router generate --app-dir src/app --out src/route-manifest.ts",
    "prebuild": "next-smart-router generate --app-dir src/app --out src/route-manifest.ts"
  }
}
```

> Prefer JSON? Pass `--out src/routes.json` and import it with
> `import routes from "@/routes.json"`.

## Step 2 — Initialize once

Register the routes a single time, as early as possible. A root client
component is a good place:

```tsx
// app/smart-router-init.tsx
"use client";
import { initializeSmartRouter } from "next-smart-router";
import { ROUTES } from "@/route-manifest";

initializeSmartRouter({ routes: ROUTES });

export function SmartRouterInit() {
  return null;
}
```

```tsx
// app/layout.tsx
import { SmartRouterInit } from "./smart-router-init";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <SmartRouterInit />
        {children}
      </body>
    </html>
  );
}
```

> The call is idempotent — repeated calls are ignored unless you pass
> `{ force: true }`.

## Step 3 — Navigate

```tsx
"use client";
import { useSmartRouter } from "next-smart-router/react";

export function WorkspaceToolbar() {
  const router = useSmartRouter();

  return (
    <div>
      {/* resolved against the current pathname */}
      <button onClick={() => router.push("./settings")}>Settings</button>
      <button onClick={() => router.push("../")}>Up one level</button>
      <button onClick={() => router.fsBack()}>Back (safe)</button>
    </div>
  );
}
```

## Step 4 — Read params & breadcrumbs

```ts
import { getParams, getBreadcrumbs } from "next-smart-router";

// route: /workspaces/[id]
const { id } = getParams<["id"]>();          // client: reads window.location
getBreadcrumbs("/workspaces/42/settings");   // -> real, matchable ancestors
```
